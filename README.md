# TailorCV

TailorCV exists to be a **simple, fast and effective way to manage every job application you make**.
It generates a tailored CV for each job posting and tracks each application on a local Kanban board.

## Philosophy

- **Born to be simple.** No accounts, no setup wizards, and the board needs nothing beyond the Python standard library.
  If a feature makes it harder to use or understand, it doesn't belong here.
- **Self-hosted.** Everything runs on your own machine. The board listens only on `127.0.0.1`; nothing is sent to a cloud service.
- **Files are the source of truth.** No database. The folders and Markdown files in `generated_cvs/` are the only
  source of data — you can read, edit, back up or version them with any tool you like.

## Workflow

1. In Claude Code, run `/tailor-cv` with a job posting link. The skill generates the **Package** (CV `.md`/`.pdf`,
   plus `job_info.md` with company research and interview prep) and the **Application** (`application.md`)
   in `generated_cvs/awaiting/`.
2. Open the board and move the **Application** between stages as the hiring process moves forward.

## Board

```bash
python3 board.py              # http://127.0.0.1:8765
python3 board.py --port 9000  # another port
```

Python 3.10+ standard library only, no `pip install` needed. Listens only on `127.0.0.1`.

- **Stages** (each one is a folder): `awaiting/` → `applied/` → `in-process/` → `offer/` → `closed/`.
  Moving an Application moves its folder. When closing one, the board asks for the reason (rejected, withdrew, position closed).
- **Opened Application:** job links, CV and cover letter PDFs, rendered `job_info.md` and your notes
  (the body of `application.md`, freely editable in Markdown; `Ctrl+S` saves).
- The UI is shown in Portuguese if your browser is set to Portuguese; otherwise, in English.
- After running the skill, click **Refresh** (or reload the page) to see the new Application.

```text
generated_cvs/applied/2026-11-16_Superhuman_AI-Engineer-Mail/
├── Thiago Lelis - Superhuman.md / .pdf
├── job_info.md         # generated by the skill (can be regenerated)
└── application.md      # frontmatter (company, role, job_url, apply_url, created, closed_reason) + your notes
```
